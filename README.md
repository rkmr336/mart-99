# Mart 99 🛒

Mart 99 is a modern, fast, and fully responsive e-commerce web application designed for a seamless grocery shopping experience. It offers a clean user interface ("Red UI"), fast navigation, and real-time database updates.

## 🚀 Live Demo
**[mart-99.vercel.app](https://mart-99.vercel.app)** *(Deployed on Vercel)*

---

## ✨ Features
- **User Authentication:** Secure email/password login and registration powered by Firebase Authentication.
- **Product Catalog:** Browse through a variety of groceries including Dairy, Snacks, Vegetables, and Household items.
- **Shopping Cart System:** Add, remove, and update item quantities dynamically.
- **Checkout Process:** Smooth order placement and success tracking.
- **Order History:** Users can track and view their past orders.
- **Admin Dashboard:** Exclusive access for admins to view all placed orders, track sales, and manage store data.
- **Responsive Design:** Fully optimized for mobile, tablet, and desktop screens.

---

## 🛠️ Tech Stack & Tools Used

### Frontend
- **React.js (v18):** Core UI library for building the single-page application (SPA).
- **Vite:** Next-generation frontend tooling for ultra-fast builds and hot-module replacement.
- **Tailwind CSS:** Utility-first CSS framework for rapid and custom UI styling.
- **React Router DOM:** For seamless client-side routing between pages.
- **Lucide React:** Beautiful, consistent icon set.
- **React Hot Toast:** For interactive, lightweight push notifications and alerts.

### Backend & Database
- **Firebase Firestore:** NoSQL cloud database used to store products, user profiles, and order history in real-time.
- **Firebase Authentication:** Handles secure user sign-ups, log-ins, and session management.

### Deployment
- **Vercel:** Automated CI/CD pipeline for instant production deployments directly from the GitHub repository.

## ⚙️ Local Development Setup

To run this project locally on your machine, follow these steps:

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rkmr336/mart-99.git
   cd mart-99
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Build for production:**
   ```bash
   npm run build
   ```
